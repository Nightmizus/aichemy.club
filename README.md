# 炼丹社 AIchemy · 满屏像素实验室

接手开发请先阅读 [开发交接说明](DEVELOPMENT.md)；服务器发布和域名状态分别见 [部署手册](DEPLOYMENT.md) 与 [部署状态](DEPLOYMENT-STATUS.md)。

首页保留原有满屏像素实验室和周围设备构图，中央改为带加料口、热风管道、炉膛和出料槽的工业高炉。悬浮核心略微上移，更大的像素标题叠在炉身上方。动画画布始终占一个完整视口。

直接打开 `index.html`，或运行 `npm run dev` 后访问 `http://localhost:3000`。无构建步骤、无外部运行依赖。

## 窗口与导航

- 桌面的四个监测窗口保留训练进度、损失曲线、GPU/显存和数据日志，采用大小不一的半透明小窗，错开散落在场景四周。以 1440×900 桌面为例，面积约为上一版的 16%～24%；窗口位置固定。
- 悬浮核心下方显示大标题「炼丹社AIchemy」和小标题「硬核AI研究社团@sdsz」。标题背后以羽化遮罩实现轻微的 3px 局部背景模糊，文字保持清晰。标题、导航和下滑板块标题统一使用本地 Unifont 点阵字体。
- 下方中央的三个导航保留标题栏、低对比度窗口控制符和轻微浮动，加大中文名称，从左到右为青色「正在运行的服务」、紫色「资讯与活动」、金色「加入社团！」。下滑列表沿用对应颜色与像素边框。
- 三个入口依次跳转本页 `#services`、`#activities`、`#join`；「加入社团！」下显示「添加社长微信」。
- 下滑导航增加「社区」入口，页面最底部的社区模块分为「友社」和「友链」：友社链接 `ht2.club`，友链链接 `mizusumi.com` 与 `groovin.cn`，均在新标签页打开。
- 下滑服务与资讯活动板块采用上方标题、下方内容。资讯与活动列表只显示「炼丹社社娘形象与周边」的标题与一句摘要，点击后打开独立资讯页，完整展示四张社娘原图，支持点击放大；吧唧限量 25 个、闪卡限量 50 个，均免费发放。手机端图片逐张排列。「加入社团」位于整页最后，说明与图片横向排列，明确说明「扫码添加社长微信，加入社团」。二维码原图完整显示，不裁切，桌面宽 144px、手机宽 104～120px，支持点击查看原图和保存原图。
- 手机端工业高炉在既有比例上缩小 12%，隐藏 TRAIN.EXE、COMPUTE.SYS、LOSS.MONITOR、DATA.STREAM 四个绿色监测窗口；标题、导航及其他界面尺寸不变。3D 与 PIXEL 均适用，画布仍占满视口，动画继续播放。手机触控横屏同样适配，桌面和平板保留原来的炉体大小和四个监测窗口。
- 下滑时主标题先以原尺寸随页面上移，抵达屏幕顶部后才逐步缩小、移至左上角，成为固定导航栏的品牌入口；导航随之出现，链接位于右侧。点击标题返回首屏，反向滚动时恢复原位置。导航链接高亮当前板块，锚点跳转预留顶部导航的高度。
- 内容区保留现有实验室底部的工作台、管线和地面作为固定背景。背景为原画布的渐隐静帧，不额外启动动画循环；滚回首屏后背景与顶部导航淡出。

## 动画与操作

核心、机械臂、服务器、冷却装置、工作台、数据瓶架、存储卡、终端、风扇、吊灯和管线均保留。高炉炉膛中的神经网络随炉火闪动，顶部持续加料，底部流出亮色熔流。数值为训练场景模拟，不进行真实模型训练。

默认显示高炉。在地址后添加 `?furnace=cauldron` 可对照原丹炉造型，标题与导航布局相同。

首次打开且没有保存样式偏好时默认进入 3D；右上角的「PIXEL / 3D」开关可切换首屏。3D 首屏采用左侧两行大标题、右侧工业高炉的构图。高炉由锥形炉身、加料斗、侧面下降管、热风围管、双层检修平台和支撑钢架组成；料车沿斜轨往返，炉膛持续燃烧，出铁槽流出亮色铁水。桌面和平板沿用原来的投影比例，手机端在既有比例上缩小 12%；高炉轮廓保留完整的炉体与钢架结构。七条数据流汇入顶部，金色模型核心及环绕轨道继续旋转，底部为工业仪表刻度环；保留散点入场与完整粒子动效。

青色与金色两片流动点阵曲面贯穿整个视口，背景有大范围的冷暖辉光。桌面三个入口沿左下方排列，TRAIN.EXE 小窗放在高炉正左侧、标题与炉体之间的空位，COMPUTE.SYS 保持在上方空白区域；手机端隐藏这四个监测窗口，给高炉留出完整展示空间。标题滚动碰顶后合为一行收进导航栏，高炉、料车和铁水同时逐渐回到中央并重组为神经网络，进入内容区后降为每秒 30 帧。

样式选择保存在本地存储中，刷新后保持；`?scene=3d` 或 `?scene=pixel` 可临时预览而不保存。两种样式共用模拟时钟和暂停按钮，切换时监测窗口的数值不会跳变。PIXEL 模式保持原有构图。

移动鼠标或触摸场景会显示右上角暂停按钮；在首页按空格也可暂停或继续。暂停会同步冻结动画、导航浮动、模拟指标和曲线。滚动到内容区后，空格保留正常的页面滚动行为。

系统启用「减少动态效果」时默认暂停、停用平滑滚动，标题直接切换至导航栏位置。场景离开视口或页面转入后台时暂停绘制。

本地预览自动检测首页文件变化并刷新，资源使用内容版本号并禁用缓存。直接打开或部署 HTML 时不会请求预览服务的刷新接口。

## 文件

- `index.html`：场景、四个监测窗口、三个导航与下滑板块。
- `styles.css`：窗口外观、嵌入位置和响应式布局。
- `furnace.js`：满屏像素动画与高炉 / 丹炉造型。
- `furnace3d.js`：可切换的 3D 点阵工业高炉动画。
- `assets/wechat-qr.jpg`：用户提供的微信二维码原图。
- `assets/news/mascot.html`：独立资讯详情页，顶部和底部可返回首页资讯列表。
- `assets/mascot/`：资讯使用的四张社娘原图。
- `assets/unifont-news.woff2`：资讯导航使用的 Unifont 补充字形，与原字库共用授权。
- `app.js`：模拟指标、导航浮动、暂停控制、滚动标题与背景衔接。
- `server.mjs`：本地预览服务器。
- `poster/`：独立海报，与网页分开维护。

部署网站时上传根目录 HTML、CSS、JS（含 `furnace3d.js`）、`favicon.svg` 及 `assets/`。字体授权见 `assets/NotoSansSC-OFL.txt` 和 `assets/Unifont-OFL.txt`。Unifont 点阵字体子集仅约 5 KB，随网站部署，不依赖第三方字体服务。

与 Hatchery 共用阿里云服务器的具体步骤见 [部署交接手册](DEPLOYMENT.md)，包含目录、资源路径隔离、Nginx、域名与 HTTPS、验收和回滚。生产部署请使用手册中的发布包，不直接运行本地预览服务器。

2026-09-26 已完成服务器部署，临时预览为 `http://39.106.77.105/`；正式域名尚待 ICP 备案和 HTTPS 启用。发布版本、验收及收尾步骤见 [当前部署状态](DEPLOYMENT-STATUS.md)。

语法检查：`npm run check`。更改预览端口：`npm run dev -- --port 8080`。
